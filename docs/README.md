# 制作課題(Qiita + Line)

## 主な機能

- Lineみたいなトーク機能+チーム作成+参加+退会+参加するときに制限をかける。
- Qiitaみたいなブログ投稿機能(投稿先指定private,public,team)

### 認証機能

- ログイン(メールアドレスとパスワード)
- 新規登録(メールアドレスとパスワード*2)=時間あったら確認機能実装
- パスワードの再設定(運営に問い合わせて修正可能)
- プロフィール(名前、アイコン、自己紹介):タグ付け追加出来たら

### チーム

- チーム一覧ページ(検索)
- 作成・削除・編集(ユーザの追加(招待)、退会、権限管理、参加に承認が必要、チーム名変更、アイコン、公開、非公開)
- チームトーク画面(メンバー表示、コメント表示)
- 参加申請

### ホーム

- チームトーク一覧(検索)
- チーム作成ページへ遷移

### トーク

- すべてがチームトーク判定(privateで個人チャットみたいな感じ)
- 検索
- 割り当てられたブログ
- 画像アップロード
- メンバー一覧
- チーム設定リンク


### ブログ機能

- ブログ作成編集削除(記事の公開、非公開、チーム指定、タイトル、本文)
- タグ検索
- ブログ詳細ページ(タイトル、タグ、本文、投稿者、いいね、コメント、関連記事)

### 通知
- 新着
- チーム参加申請
- コメント返信
- チーム招待

## ページごとの機能

### 1. 認証系ページ

#### ログインページ
- メールアドレス入力
- パスワード入力
- ログイン処理
- パスワード再設定案内（問い合わせリンク）

#### 新規登録ページ
- メールアドレス
- パスワード
- パスワード確認
- 登録処理
- （時間があれば）メール認証フロー

#### プロフィール編集ページ
- 名前編集
- アイコンアップロード
- 自己紹介編集
- タグ付け（任意）
- 保存

### 2. ホームページ（ダッシュボード）

#### ホーム
- 参加中チームのトーク一覧
- トーク検索
- チーム作成ページへのリンク
- 通知一覧（新着・申請・コメント・招待）

### 3. チーム関連ページ

#### チーム一覧ページ
- チーム検索
- 公開チームの一覧表示
- チーム詳細ページへの遷移
- 参加申請ボタン

#### チーム詳細ページ
- チーム名
- アイコン
- 公開/非公開
- メンバー一覧
- 参加申請ボタン（承認制の場合は申請待ち表示）

#### チーム作成ページ
- チーム名
- アイコン
- 公開/非公開設定
- 参加に承認が必要かどうか
- 作成ボタン

#### チーム設定ページ（管理者のみ）
- チーム名変更
- アイコン変更
- 公開/非公開切り替え
- 承認制のON/OFF
- メンバー管理（追加・招待・削除）
- 権限管理
- チーム削除
- 退会ボタン（一般メンバー）

### 4. トーク（チャット）ページ

#### チームトーク画面

- メッセージ一覧
- メッセージ投稿（markdown）書いてる最中にプレビューを表示
- 画像アップロード
- メンバー一覧表示
- チーム設定ページへのリンク
- 割り当てられたブログ一覧（チーム内記事）

#### トーク検索ページ
- トーク内検索
- メッセージフィルタ

### 5. ブログ（Qiita風）ページ

#### ブログ一覧ページ
- 公開記事一覧
- タグ検索
- チーム指定記事のフィルタ
- 自分の投稿一覧

#### ブログ詳細ページ
- タイトル
- タグ
- 本文
- 投稿者
- いいね
- コメント
- 関連記事

#### ブログ作成ページ
- タイトル
- 本文
- 公開設定（public / private / team）
- タグ設定
- 投稿ボタン

#### ブログ編集ページ
- タイトル編集
- 本文編集
- 公開設定変更（public / private / team）
- タグ編集
- 削除ボタン

### 6. 通知ページ

#### 通知一覧
- 新着通知
- チーム参加申請通知
- コメント返信通知
- チーム招待通知
- 通知既読処理

### 7. その他（運営向け）

#### パスワード再設定（運営）
- ユーザー検索
- パスワードリセット処理
