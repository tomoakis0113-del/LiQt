# 制作課題(Qiita + Line)

## 主な機能

- Lineみたいなグループトーク機能（作成・参加・退会・招待・権限管理）
- Qiitaみたいなブログ投稿機能（公開先指定: public / private / team）
- ユーザープロフィール管理（名前・自己紹介・タグ）
- 通知機能（新着・申請・コメント返信・招待）

### 認証機能

- ログイン（メールアドレスとパスワード）
- 新規登録（ユーザID・表示名・メールアドレス・パスワード）
- メール認証（トークン入力・再送信）
- パスワードの再設定(運営に問い合わせて修正可能)
- プロフィール（名前、アイコン、自己紹介、タグ）

### チーム

- 公開グループ一覧ページ（検索）
- 作成・削除・編集（招待、退会、権限管理、チーム名変更、アイコン、公開/非公開）
- グループトーク画面（メッセージ表示、メンバー表示、チーム内ブログ表示）
- 参加（公開グループは遷移時参加）

### ホーム

- 参加中グループ一覧（最新チャット表示）
- グループ作成ページへの遷移

### トーク

- グループチャット（Markdown投稿・プレビュー対応）
- グループ内メッセージ検索
- 割り当てられたブログ表示
- 画像アップロード
- メンバー一覧
- チーム設定リンク


### ブログ機能

- ブログ作成編集削除(記事の公開、非公開、チーム指定、タイトル、本文)
- タグ検索
- ブログ詳細ページ(タイトル、タグ、本文、投稿者、いいね、コメント、関連記事)

### 通知
- 新着
- チーム参加申請
- コメント返信
- チーム招待

## ページごとの機能

### 1. 認証系ページ

#### ログインページ
- メールアドレス入力
- パスワード入力
- サインインボタン
	- サインイン処理（成功: ダッシュボードへ遷移 / 失敗: エラーメッセージ表示）
- パスワード再設定案内（問い合わせリンク）
- サインアップページへのリンク

#### 新規登録ページ
- ユーザID（プライマリ・変更不可）
- 表示名
- メールアドレス
- パスワード
- パスワード確認
- サインアップボタン
	- サインアップ処理（成功: メール認証ページへ遷移 / 失敗: エラーメッセージ表示）

#### メール認証ページ
- メールアドレス入力
- トークン入力
- 認証ボタン
	- 認証処理（成功: サインインページへ遷移 / 失敗: エラーメッセージ表示）
- トークン再送信ボタン（30秒クールダウン）

### 2. 共通レイアウト（サインイン必須）

#### ヘッダ
- ロゴ
- 検索（ユーザID / グループ / ブログ）

#### フッター
- プロフィールページリンク
- ダッシュボードページリンク
- ブログページリンク

### 3. プロフィールページ

#### 自分のプロフィール
- アイコンアップロード
- ユーザID表示
- 名前編集
- 自己紹介編集
- タグ編集
- 編集ボタン（成功: 更新表示 / 失敗: エラーメッセージ表示）

#### 他人のプロフィール
- アイコン
- ユーザID
- 名前
- 自己紹介
- タグ
- チャットを開始
- ブロックボタン
- ブログ一覧（リンク付き）

### 4. ダッシュボードページ

#### ダッシュボードトップ
- 参加済みグループ一覧（最新チャット内容を表示）
- グループ作成ページへのリンク

#### グループ作成ページ
- グループ名
- アイコンアップロード
- 公開/非公開設定
- ユーザ招待（ユーザID入力・検索可）
- 作成ボタン
	- 作成処理（成功: グループチャットページへ遷移 / 失敗: エラーメッセージ表示）

#### グループチャットページ
- グループ名表示
- アイコン表示
- チームのブログ一覧（リンク付き）
- メッセージ一覧（アイコン付き、アイコン押下でプロフィール遷移）
- グループ編集ページへのリンク
- メッセージ投稿（Markdown、入力中プレビュー）
- 画像アップロード

#### グループ編集ページ
- 管理者機能
	- メンバー管理（招待・削除・権限変更）
	- 公開/非公開切り替え
	- グループ名変更
	- アイコン変更
	- 編集ボタン（成功: グループチャットページへ遷移 / 失敗: エラーメッセージ表示）
	- グループ削除ボタン
- メンバー機能
	- メンバー一覧（アイコン付き、アイコン押下でプロフィール遷移）
	- 退会ボタン

### 5. オープンチャット一覧ページ

- 公開グループ一覧（最新チャット内容を表示）
- グループ検索機能
- グループチャットページへのリンク（押下時に参加）

### 6. トーク（チャット）ページ

#### チームトーク画面

- メッセージ一覧
- メッセージ投稿（markdown）書いてる最中にプレビューを表示
- 画像アップロード
- メンバー一覧表示
- チーム設定ページへのリンク
- 割り当てられたブログ一覧（チーム内記事）

#### トーク検索ページ
- トーク内検索
- メッセージフィルタ

### 7. ブログ（Qiita風）ページ

#### ブログ一覧ページ
- 公開記事一覧
- 非公開記事一覧
- タグ検索
- チーム指定記事のフィルタ
- 自分の投稿一覧

#### ブログ詳細ページ
- タイトル
- タグ
- 本文
- 投稿者
- いいね
- コメント
- 関連記事

#### ブログ作成ページ
- タイトル
- 本文
- 公開設定（public / private / team）
- タグ設定
- 投稿ボタン

#### ブログ編集ページ
- タイトル編集
- 本文編集
- 公開設定変更（public / private / team）
- タグ編集
- 削除ボタン

### 8. 通知ページ

#### 通知一覧
- 新着通知
- チーム参加申請通知
- コメント返信通知
- チーム招待通知
- 通知既読処理

### 9. その他（運営向け）

#### パスワード再設定（運営）
- ユーザー検索
- パスワードリセット処理
