# LiQt各ページにおける項目
このドキュメントでは、LiQtの各ページにおいて必要な項目や機能について説明します。各ページの内容を充実させるために、以下の項目を参考にしてください。
[readme.md](./README.md)の内容をもとに、各ページに必要な項目をリストアップしています。必要に応じて、追加の項目や機能を検討してください。

## 語句定義
- サインイン：ユーザーがLiQtにログインすること。
- サインアップ：ユーザーがLiQtに新規登録すること。
- サインアウト：ユーザーがLiQtからログアウトすること。
- プロフィール：ユーザーの基本情報や自己紹介を表示するページ。
- ユーザー：LiQtを利用する個人。プロフィールを持ち、グループに参加し、ブログを投稿することができる。
- グループ：ユーザーが参加するコミュニティ。公開/非公開の設定が可能。
- チャット：グループ内でのメッセージのやり取り。テキスト、画像、ファイルの送信が可能。
- ブログ：ユーーが投稿する記事。公開設定（public / private / team）が可能。
- タグ：ブログやユーザープロフィールに付与するキーワード。検索やフィルタリングに使用。
- 通知：ユーザーに対するイベントの知らせ。新着、申請、コメント、招待などの通知が含まれる。

## 認証系ページ authentication

### サインインページ
- メールアドレス入力
- パスワード入力
- サインインボタン
    - サインイン処理
        - 成功：ダッシュボードページへ遷移
        - 失敗：エラーメッセージ表示

- リンク
    - パスワード再設定案内（問い合わせリンク）
    - サインアップページへのリンク

### 新規登録ページ
- ユーザID(プライマリ且つ変更不可)
- 表示名(名前)
- メールアドレス
- パスワード
- パスワード確認
- サインアップボタン
    - サインアップ処理
        - 成功：メール認証ページへ遷移
        - 失敗：エラーメッセージ表示

### メール認証ページ
- メールアドレス入力
- トークン入力
- 認証ボタン
    - 認証処理
        - 成功：サインインページへ遷移
        - 失敗：エラーメッセージ表示

- トークン再送信ボタン
    - トークン再送信処理
        - 30秒のクールダウンタイム

## ページ
- サインイン必須
- ヘッダ
    - ロゴ
    - 検索
        - ユーザID検索
        - グループ検索
        - ブログ検索
- フッター
    - プロフィールページリンク
    - ダッシュボードページリンク
    - ブログページリンク

### プロフィールページ
- アイコン
- ユーザID
- 名前(編集可能)
- 自己紹介(編集可能)
- タグ(編集可能)
- 編集ボタン
    - 編集処理
        - 成功：プロフィールページを更新して表示
        - 失敗：エラーメッセージ表示

### ダッシュボードページ

#### ダッシュボードトップ
- グループ一覧(参加済み)(最新のチャット内容を表示)
- グループ作成ページへのリンク

#### グループ作成ページ
- グループ名入力
- アイコンアップロード
- 公開/非公開設定
- ユーザ招待（ユーザID入力 検索も可）
- 作成ボタン
    - 作成処理
        - 成功：グループチャットページへ遷移
        - 失敗：エラーメッセージ表示

#### グループチャットページ
- グループ名表示
- アイコン表示
- チームのブログ一覧(リンク付き)
- メッセージ一覧(アイコン付き)->アイコンクリックでプロフィールページへ遷移
- グループ編集ページへのリンク
- メッセージ投稿（markdown）書いてる最中にプレビューを表示
- 画像アップロード

#### グループ編集ページ
- 管理者
    - メンバ管理(招待(ユーザID)・削除・権限変更)
    - 公開/非公開切り替え
    - グループ名変更
    - アイコン変更

    - 編集ボタン
        - 編集処理
            - 成功：グループチャットページへ遷移
            - 失敗：エラーメッセージ表示

    - グループ削除ボタン
- メンバー
    - メンバー一覧(アイコン付き)->アイコンクリックでプロフィールページへ遷移
    - 退会ボタン

#### オープンチャット一覧ページ
- 公開グループ一覧(最新のチャット内容を表示)->グループチャットページへのリンク(押した時点で参加)
- グループ検索機能

#### プロフィールページ(他人)
- アイコン
- ユーザID
- 名前
- 自己紹介
- タグ
- チャットを開始
- ブロックボタン
- ブログ一覧(リンク付き)

### ブログ（Qiita風）ページ

#### ブログ一覧ページ
- 公開記事一覧
- 非公開記事一覧
- タグ検索
- グループ指定記事のフィルタ
- 自分の投稿一覧

#### ブログ詳細ページ
- タイトル
- タグ
- 本文
- 投稿者
- いいね
- コメント
- 関連記事

#### ブログ作成ページ
- タイトル
- 本文
- 公開設定（public / private / team）
- タグ設定
- 投稿ボタン

#### ブログ編集ページ
- タイトル編集
- 本文編集
- 公開設定変更（public / private / team）
- タグ編集
- 削除ボタン
