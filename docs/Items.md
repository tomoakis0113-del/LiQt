# LiQt各ページにおける項目
このドキュメントでは、LiQtの各ページにおいて必要な項目や機能について説明します。各ページの内容を充実させるために、以下の項目を参考にしてください。
[readme.md](./README.md)の内容をもとに、各ページに必要な項目をリストアップしています。必要に応じて、追加の項目や機能を検討してください。

## 1. 認証系ページ authentication

### ログインページ
- メールアドレス入力
- パスワード入力
- ログイン処理
- パスワード再設定案内（問い合わせリンク）

### 新規登録ページ
- メールアドレス
- パスワード
- パスワード確認
- 登録処理
- （時間があれば）メール認証フロー

### プロフィール編集ページ
- 名前編集
- アイコンアップロード
- 自己紹介編集
- タグ付け（任意）
- 保存

## 2. ホームページ（ダッシュボード）

### ホーム
- 参加中チームのトーク一覧
- トーク検索
- チーム作成ページへのリンク
- 通知一覧（新着・申請・コメント・招待）

## 3. チーム関連ページ

### チーム一覧ページ
- チーム検索
- 公開チームの一覧表示
- チーム詳細ページへの遷移
- 参加申請ボタン

### チーム詳細ページ
- チーム名
- アイコン
- 公開/非公開
- メンバー一覧

### チーム作成ページ
- チーム名
- アイコン
- 公開/非公開設定
- 作成ボタン

### チーム設定ページ（管理者のみ）
- チーム名変更
- アイコン変更
- 公開/非公開切り替え
- 承認制のON/OFF
- メンバー管理（追加・招待・削除）
- 権限管理
- チーム削除
- 退会ボタン（一般メンバー）

## 4. トーク（チャット）ページ

### チームトーク画面

- メッセージ一覧
- メッセージ投稿（markdown）書いてる最中にプレビューを表示
- 画像アップロード
- メンバー一覧表示
- チーム設定ページへのリンク
- 割り当てられたブログ一覧（チーム内記事）

### トーク検索ページ
- トーク内検索
- メッセージフィルタ

## 5. ブログ（Qiita風）ページ

### ブログ一覧ページ
- 公開記事一覧
- タグ検索
- チーム指定記事のフィルタ
- 自分の投稿一覧

### ブログ詳細ページ
- タイトル
- タグ
- 本文
- 投稿者
- いいね
- コメント
- 関連記事

### ブログ作成ページ
- タイトル
- 本文
- 公開設定（public / private / team）
- タグ設定
- 投稿ボタン

### ブログ編集ページ
- タイトル編集
- 本文編集
- 公開設定変更（public / private / team）
- タグ編集
- 削除ボタン

## 6. 通知ページ

### 通知一覧
- 新着通知
- チーム参加申請通知
- コメント返信通知
- チーム招待通知
- 通知既読処理

## 7. その他（運営向け）

### パスワード再設定（運営）
- ユーザー検索
- パスワードリセット処理
